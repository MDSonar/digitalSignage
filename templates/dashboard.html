    Settings

    Configure Slack integration and API keys

    OAuth & Permissions → Bot User OAuth Token
    Basic Information → App Credentials
    Right-click channel → View channel details → Copy ID
    1

    Create a Slack App

    Go to api.slack.com/apps → Create New App → From scratch. Name it "Litmus Signage".

    2

    Configure Event Subscriptions

    Enable Events and set the Request URL to your server's webhook endpoint.

    https://your-server:5000/webhooks/slack
    3

    Add OAuth Scopes

    Under OAuth & Permissions, add these Bot Token Scopes:

    files:read chat:write channels:history
    4

    ngrok (local setup)

    Expose port 5000 to the internet using ngrok for webhook delivery:

    ngrok http 5000
    5

    Upload & Schedule

    Upload a file to your Slack channel with a comment:

    schedule: 14:30-15:00
