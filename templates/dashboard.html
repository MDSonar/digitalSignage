🔔 Slack Integration

Slack App → OAuth & Permissions → Bot User OAuth Token

Set any secret key here. Use the same key in Power Automate HTTP header X-Ingest-Key. Prevents unauthorized access.
📡 Webhook URL for Slack Event Subscriptions:
https://<your-ngrok-url>/webhooks/slack

📦 Phase 1 — Create the Slack App
1
Open Slack API portal
Go to api.slack.com/apps → click Create New App → choose From scratch
2
Name & workspace
App Name: Litmus Signage → select your company workspace → click Create App
3
Copy Signing Secret (do this first)
Left sidebar → Basic Information → scroll to App Credentials → click Show next to Signing Secret → copy it
✅ Paste into Signing Secret field in Credentials tab
🔑 Phase 2 — Add Scopes & Install App
4
Add Bot Token Scopes
Left sidebar → OAuth & Permissions → scroll to Scopes → Bot Token Scopes → Add each:
files:read — download uploaded files
chat:write — send DM replies to users
channels:join — join channels to receive events
im:write — open DM conversations
5
Install App to Workspace
Scroll to the top of OAuth & Permissions page → click Install to Workspace → click Allow
⚠️ Button shows "Request to Workspace Install Submitted"?
Your workspace requires admin approval. Two options:
1. If you're the admin: go to your-workspace.slack.com/apps/manage → Pending Requests → Approve
2. Ask your Slack workspace admin to approve the install request
6
Copy Bot Token
After install, Bot User OAuth Token appears — starts with xoxb- → copy it
✅ Paste into Bot Token field in Credentials tab
📡 Phase 3 — Enable File Upload Events
7
Start ngrok tunnel
On your desktop (outside Docker), run:
ngrok http 5000
Copy the https://xxxx.ngrok.io URL shown
8
Set Webhook URL in Slack
Left sidebar → Event Subscriptions → toggle Enable Events ON
Paste into Request URL:
https://xxxx.ngrok.io/webhooks/slack
Slack will verify it — Flask must be running ✓
9
Subscribe to file_shared event
Under Subscribe to bot events → Add Bot User Event → search and add:
file_shared — fires when a file is uploaded to a channel
Click Save Changes
🆔 Phase 4 — Channel ID & Bot Invite
10
Get Channel ID
In Slack, right-click your channel (e.g. #signage-integration-gcc) → View channel details → scroll to very bottom → copy Channel ID (looks like C08XXXXXX)
✅ Paste into Test Channel ID field in Credentials tab
11
Invite bot to the channel
Inside #signage-integration-gcc, type in the message box:
/invite @Litmus Signage
The bot must be in the channel to receive file events and post replies.
✅ Phase 5 — Test & Go Live
12
Save credentials & test
Go to Credentials tab → fill all 3 fields → Save Settings → Test Connection
A message should appear in your Slack channel ✓
13
Upload a PPT with schedule comment
In #signage-integration-gcc, upload any .pptx file and add a message:
schedule: 14:00-14:30
You'll get a DM confirming the playlist was created and scheduled automatically.
⚠️ ngrok URL changes on each restart. When ngrok restarts, update the Request URL in Slack Event Subscriptions (Step 8). Get a free static ngrok domain at dashboard.ngrok.com → Domains to avoid this.
